Полноэкранный браузер для андроида на базе библиотеки android webview. Включает полноэкранный режим андроид, скрывает кнопки навигации и полоску уведомлений, адресная строка и кнопки управления браузером не отнимают полезную площадь экрана. Меню управления с данными элементами вызывается касанием 3мя пальцами.
